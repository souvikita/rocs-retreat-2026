# Posters

One PNG per participant, named after the person as shown on the page, lower-case,
spaces replaced by hyphens, Norwegian letters simplified (ø→o, å→a, æ→ae):

    petra-kohutova.png
    luc-rouppe-van-der-voort.png
    semya-a-tonnessen.png

The page looks for `posters/<name>.png` and shows a placeholder until the file exists.
